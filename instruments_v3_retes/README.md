# النسخة الثالثة: عناكب الأسطرلابات منقولة يدوياً من صور الكتاب

هذه نسخة مستقلة. النسختان `instruments/` و`instruments_v2/` باقيتان كما هما.

تشمل ٢٥ أسطرلاباً ذات عنكبوت ذهبي، ولكل آلة مجموعة ملفاتها كاملة: CNC وPDF وREADME. والفرق عن النسخة الثانية في **العنكبوت** وحده.

## طريقة النقل
1. تصحيح منظور صورة الوجه.
2. قياس حجم العنكبوت ودورانه في الصورة بمطابقة حلقة البروج المحسوبة على حواف الصورة.
3. قراءة عناصر الزخرف يدوياً على شبكة إحداثيات فوق الصورة: القضبان والأشرطة المنحنية والحلقات والأقواس والأزرار وشكل المؤشرات (لهبي، خنجري، لوزي، معقوف). تحويل كل عنصر إلى شكل متجه دقيق.
4. **مواضع رؤوس المؤشرات محسوبة** لسنة الصنع، فهي دقيقة فلكياً.

## صور المطابقة
في `_rete_checks/` لكل آلة صورة الكتاب وفوقها حدود العنكبوت المرسوم باللون البنفسجي.

## حدود هذه النسخة
- **الهيكل الرئيسي يطابق الصورة**: الحلقة الخارجية، وحلقة البروج، وخط الاعتدال، والقضبان.
- **الزخارف الدقيقة تقريبية**: الأشرطة المتشابكة والأوراق والصور مبسطة، وليست نسخة مطابقة خطاً بخط. والفرق أوضح في الآلات الفارسية والعثمانية كثيفة الزخرف: A2.20 وA2.16 وA2.32 وA2.27، وفي الأوروبية A2.09 وA2.10 وA2.04.
- عدد المؤشرات وأشكالها حسب الكتاب، لكن ربط كل مؤشر بالهيكل اختير آلياً.
- العناصر في `tools/astro_v2/rete_manual.py` قابلة للتعديل، وإعادة التوليد بالأمر:
  `MANUAL_RETE=1 python3 tools/astro_v2/build.py --only A2.14 --book … --out instruments_v3_retes`
